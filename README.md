# Trap Revenant (Custom Archetype)

A custom 9-card "Trap Revenant" archetype for [ProjectIgnis EDOPro](https://github.com/ProjectIgnis/EDOPro).

## Installation

1. Download this repository.
2. Copy the files into your EDOPro install folder like so:

   | File(s) | Destination |
   |---|---|
   | `*.png` / `*.jpg` (card art) | `ProjectIgnis/expansions/pics/` |
   | `*.lua` (card scripts) | `ProjectIgnis/expansions/script/` |
   | `TrapRevenant.cdb` | `ProjectIgnis/expansions/` |

3. Restart EDOPro. The cards will now appear in the card editor / deck builder — search for "Trap Revenant" in the database.

## Notes

- This is a fan-made, unofficial expansion. Card IDs are in the `900000000+` range to avoid colliding with real cards.
- If cards don't show up, double-check the `.cdb` is directly in `expansions/` (not a subfolder) and that the scripts are directly in `expansions/script/`.
